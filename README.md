# 面具之下：失名之夜

一款以调查、交谈、出示证物和身份推理为核心的网页视觉小说原型。

当前版本为纯静态前端，可以直接通过 GitHub Pages 游玩。玩家需要调查四个记忆房间，将证物相互关联，并向不同人物出示关键物品，以解锁新话题和后续章节。

## 当前功能

- 完整序章至终幕流程
- 场景区域调查与动态放大镜
- 多人物交谈及递进话题
- 出示证物与错误证物反馈
- 大图详情、缩略图切换与证物关联推理
- 取得证物时的资料卡演出
- 本机保存、继续游戏、返回标题与章节进度图
- 人物姿势切换、眨眼及情绪震动
- 分场景背景音乐、交互音效与音量控制
- 四段记忆回答与最终身份推理
- 手机与桌面屏幕自适应

## 后续计划

- 接入数据库同步玩家进度与回答
- 增加账号或匿名存档标识
- 完善触屏操作、音效与更多人物动画

项目目前不收集或上传玩家输入；存档与回答只保存在当前浏览器的本机存储中。音乐与音效来源及许可证记录在 `assets/audio/CREDITS.md`。
