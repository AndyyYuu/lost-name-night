# 面具之下：失名之夜

一款以调查、交谈、出示证物和身份推理为核心的中文网页视觉小说。

当前为第 21 轮证物美术整理版，沿用第 20 轮完整重修剧情，纯静态前端，无需数据库。玩家从一封无名请柬出发，调查四个记忆房间，核对彼此关联的旧物，并在逐句质询中区分「看起来有关」与「足以证明」。故事包含序章、八章主线与尾声。

详细修改、含剧透的证据链、参考资料及本轮美术生成记录见 [FINAL_EDITION.md](FINAL_EDITION.md)。

第 21 轮统一全部 40 项证物的暖灰米色底：清除旧图集黑雾、改用独立透明物件、将推理结果做成清晰记录图；缩略图、大图、获取弹窗、出示及对照共用相同素材。沿用 v2 存档，无需重新开始。新增素材与完整提示词见 [证物美术记录](assets/evidence-clean/GENERATED.md)。

## 当前功能

- 完整序章至尾声流程，以及两种自主选择的终幕
- 场景区域调查与动态放大镜
- 多人物交谈及递进话题
- 出示证物与错误证物反馈
- 黑金证物簿、大图详情、缩略图与五组手动选择证物的关联检查
- 取得证物时的资料卡演出
- 自动存档、手动保存、继续游戏、对话回看与不剧透的旅程进度
- 人物姿势切换、眨眼及情绪震动
- 分场景背景音乐、交互音效与音量控制
- 三轮逐句质询、追问、出示反证及独立的最终身份核验
- 四段可选择保留的个人记忆；终幕可以分享一份改写副本，也可以全部保留
- 八页可翻阅的私人手札，可下载为离线 HTML 阅读或打印
- 手机与桌面屏幕自适应

## 本地运行

将本目录作为任意静态服务器的站点根目录。例如已安装 Python 时，在此目录执行：

```sh
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。首次点击后才会按浏览器政策播放音频；右上角可调节音乐与音效。

## 操作与存档

- 点击对话框或按 Enter / Space：先显示整句，再继续。
- J：打开或关闭证物簿。L：回看对话。Esc：关闭当前浮层。
- 调查时可以点击物件区域，或用底部「调查」查看可调查物件。
- 对话、物件、出示证物共同解锁流程。「拾一提示」会逐层提供帮助。
- 质询与手札可使用左右方向键。选错证物可以重试，不会扣掉进度。
- 本轮剧情与证据链已重写，使用独立的 v2 存档，建议从请柬重新开始。旧版 v1 存档不被删除或覆盖，也不自动迁入新剧情。
- 清除浏览器数据或换浏览器会失去本机进度；重要的个人文字可在结尾下载手札保留。

## 数据与素材

不收集或上传玩家输入，不要求输入真实姓名，也不采集生物识别数据。剧情中的指印仅是虚构的证物图示；代号、回答与进度只保存在当前浏览器的本机存储中。向角色分享记忆也是本地剧情交互，不会发给其他玩家。

游戏背景、立绘和道具沿用项目原创生成素材，新增背景清理记录见重修说明。音乐与音效来源及许可证见 [assets/audio/CREDITS.md](assets/audio/CREDITS.md)。
